# Style 03 — Apple / Notion Style

خلفية بيضاء، مساحات فارغة سخية، بطاقات دائرية ناعمة، لون واحد مقتصد يُستخدم بحذر شديد. النقيض البصري الكامل لـ Style 01 وStyle 02 الغامقين.

## الملفات

| الملف | المحتوى |
|---|---|
| `slides.html` | الشرائح السبع، نفس مثال المحتوى بالنظامين السابقين للمقارنة |
| `components.html` | مكتبة المكوّنات |
| `README.md` | هذا الملف |

## Typography

نفس نظام الخطوط الثابت عبر الأنظمة الأربعة: **عربي:** IBM Plex Sans Arabic · **لاتيني:** Inter · **بيانات:** JetBrains Mono.
الإحساس "الراقي/التحريري" هنا يتحقق بالتباعد والأوزان لا بتغيير الخط — نفس فلسفة Apple/Notion الحقيقية (انضباط أكثر من زخرفة).

| الاسم | الوزن | الحجم | الاستخدام |
|---|---|---|---|
| Heading XL | 800 | 66px | غلاف |
| Heading L | 700 | 44px | عناوين محتوى |
| Heading M | 600 | 26px | عناوين بطاقات |
| Body | 400 | 21px | فقرات (وزن أخف من الأنظمة الأخرى — إحساس تحريري) |
| Caption | 600 (Inter) | 12.5px uppercase | Eyebrow |

## Color Palette

| Token | القيمة | الاستخدام |
|---|---|---|
| `--bg` | `#FFFFFF` | خلفية الشريحة |
| `--surface` | `#F7F7F8` | خلفية البطاقات |
| `--surface-2` | `#F0F0F2` | بطاقات متداخلة |
| `--border` | `#E5E5E8` | حدود شبه غير مرئية |
| `--text-primary` | `#1C1C1E` | نص أساسي (أسود مكسور) |
| `--text-secondary` | `#6E6E73` | نص ثانوي (رمادي Apple الكلاسيكي) |
| `--text-tertiary` | `#A0A0A5` | نص باهت جداً |
| `--accent` | `#1F6F5C` | أخضر-تيلي عميق — اللون الوحيد المسموح، يُستخدم بحذر |
| `--accent-soft` | `rgba(31,111,92,.08)` | خلفيات شارات/أيقونات فقط |
| `--success` | `#2E7D32` | إيجابي (مطفأ، غير نيون) |
| `--danger` | `#C62828` | سلبي (مطفأ) |

**قاعدة صارمة:** اللون الأساسي لا يظهر إلا بثلاثة مواضع كحد أقصى بكل شريحة (وسم، رقم/أيقونة، زر) — الباقي أبيض/رمادي بالكامل. هذا هو سرّ "premium feeling" الحقيقي.

## Spacing — شبكة 8px

`4 · 8 · 16 · 24 · 32 · 48 · 64 · 96 · 140` — هوامش أوسع من الأنظمة الأخرى (140px جانبية) لتعزيز إحساس الفراغ الفاخر.

## Shadows

ظل واحد فقط، شبه غير مرئي — لا توهج ولا تأثيرات درامية: `0 2px 12px rgba(0,0,0,.06)`
