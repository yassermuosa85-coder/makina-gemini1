# مكينة المحتوى — Gemini Edition

أداة إنتاج محتوى سوشيال ميديا باللهجة العراقية، مبنية لصانع المحتوى **@y.tyle — ترند العراق**. تطبيق ويب PWA بملف واحد (بدون خادم، بدون build step) يستخدم Google Gemini API لتوليد كاروسيلات، هوكات وسكربتات ريلز، كابشنات، خطط محتوى أسبوعية، وأكثر — كل النصوص باللهجة العراقية البحتة.

## المميزات

| الأداة | الوظيفة |
|---|---|
| 🏭 كاروسيل | توليد شرائح انستغرام كاملة + كابشن، مع تصدير PNG بدقة 1080×1350 |
| 🎣 هوكات | 5 هوكات + سكربت ريل بالثواني + اقتراحات ثمبنيل |
| ✍️ كابشن | كابشن انستغرام/تيك توك كامل (هوك + قيمة + CTA + هاشتاكات) |
| 🗓️ أسبوع | خطة محتوى أسبوعية كاملة (بحث Google حي) + خطة نمو 30 يوم |
| 📡 رادار | آخر الأخبار والترندات في أي نيش، عبر Google Search grounding |
| 🎯 محلل | تقييم أي هوك من 10 مع نسخة محسّنة |
| 🔁 تدوير | تحويل محتوى قديم ناجح لثلاث صيغ جديدة |
| 🧵 سلسلة | تقسيم موضوع كبير لحلقات محتوى مترابطة |
| 🎭 قصص | تحويل موقف شخصي لريل بأسلوب قصصي |
| 📝 أفكار | بنك أفكار سريع |
| 💾 أرشيف | حفظ تلقائي لآخر 60 توليدة، مع بحث وفلترة وتصدير/استيراد نسخة احتياطية |

## التقنيات المستخدمة

- **Vanilla HTML / CSS / JavaScript** — بدون أي framework أو أداة بناء (build tool)
- **Google Gemini API** (`gemini-2.5-flash` الافتراضي، مع خيار `gemini-2.5-pro` و`gemini-2.0-flash`) — استدعاء مباشر من المتصفح، بوضع JSON وGoogle Search grounding
- **[html2canvas](https://html2canvas.hertzen.com/)** — لتصدير شرائح الكاروسيل كصور PNG
- **PWA** — `manifest.json` + `sw.js` (service worker بإستراتيجية Network-First) للعمل شبه الأوفلاين والتثبيت على الجوال

## بنية المشروع

```
index.html      كل التطبيق — HTML + CSS + JS في ملف واحد
manifest.json   بيانات تطبيق PWA (الاسم، الأيقونات، الألوان)
sw.js           service worker (كاش + عمل أوفلاين جزئي)
icon-192.png    أيقونة التطبيق (192×192)
icon-512.png    أيقونة التطبيق (512×512، maskable)
```

## طريقة التشغيل

المشروع ملف ثابت بالكامل — لا يحتاج تثبيت أي حزمة أو تشغيل أمر بناء.

1. افتح `index.html` مباشرة بالمتصفح، أو شغّله عبر أي خادم ثابت محلي:
   ```bash
   npx http-server .
   ```
2. من الإعدادات (⚙️ بأعلى الشاشة) الصق مفتاح Gemini API الخاص بك.
3. جاهز — ابدأ التوليد من أي تبويب.

### الحصول على مفتاح Gemini API

1. روح إلى [aistudio.google.com](https://aistudio.google.com)
2. اضغط **Get API key** وأنشئ مفتاحاً جديداً (مجاني)
3. الصقه في تبويب الإعدادات داخل التطبيق

## الخصوصية والتخزين

كل البيانات — مفتاح API، الأرشيف، بنك الأفكار، الإعدادات — تُحفظ **محلياً على جهازك فقط** عبر `localStorage`. لا يوجد خادم وسيط؛ التطبيق يستدعي Gemini API مباشرة من المتصفح.

لتفادي فقدان بيانات العمل عند مسح بيانات المتصفح أو تغيير الجهاز، يوفّر تبويب الإعدادات زري **تصدير/استيراد نسخة احتياطية** (ملف JSON واحد للأرشيف وبنك الأفكار).
